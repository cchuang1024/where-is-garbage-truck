# Where is the Garbage Truck?

台北市垃圾車即時查詢工具，純靜態網頁，部署於 GitHub Pages。

## 目標

使用者開啟頁面，按下「找最近的垃圾車」，立即顯示：

1. **最近的垃圾車站點** — 依 GPS 定位 + 目前時間，找出距離最近、還在等待或即將抵達的站點
2. **今天回收什麼** — 依星期幾顯示當日資源回收項目

## 資料來源

- **垃圾車站點**：臺北市政府環境保護局「臺北市垃圾車點位路線資訊」
  - dataset_id: `136515`（data.taipei 開放資料）
  - 4,008 筆，含路線、抵達/離開時間、地址、經緯度
  - 更新頻率：不定期
- **回收日程**：台北市固定週輪表（硬編碼）

## 出車規則

- **出車日**：週一、二、四、五、六
- **休息日**：週三、週日
- **例假日**：依環保局公告，本工具不處理（顯示提示）

## 回收日程（全市固定）

| 星期 | 收取項目 |
|------|----------|
| 週一、四 | 一般垃圾、廚餘 |
| 週二、五 | 一般垃圾、廚餘、資源回收（紙類、鐵鋁罐） |
| 週六 | 一般垃圾、廚餘、資源回收（玻璃、塑膠） |
| 週三、日 | 休息，不出車 |

## 技術架構

```
20260513_Where_is_garbage_truck/
├── index.html    ← 主頁面、UI、所有邏輯
├── data.js       ← 垃圾車站點資料（const TRUCKS = [...]）
├── README.md
└── LOG.md
```

- 純靜態，無 backend
- 定位：`navigator.geolocation.getCurrentPosition()`
- 距離計算：Haversine 公式
- 時間篩選：抵達時間 ≤ 現在 ≤ 離開時間（含 ±15 分鐘緩衝）
- 部署：GitHub Pages（HTTPS，geolocation 才能在手機上運作）

## 主要流程

```
[按下按鈕]
  → 取 GPS 座標
  → 取當下時間 + 星期幾
  → 週三/日 → 顯示「今日休息」提示
  → 篩選時間窗內站點（抵達時間在現在 ±15 分鐘內）
  → Haversine 排序
  → 顯示最近 3 個站點（距離、地點、時間、路線）
  → 顯示今日回收項目
```
