# DESIGN — design-001：主色系與營業日視覺區隔

## 設計目標

以顏色直覺傳達「今天有沒有垃圾車」，不需閱讀文字就能感知。

## CSS 框架

Tailwind CSS（CDN 引入，無 build step）

## 色彩系統

### 主色：Teal（有車日）

| 用途 | Tailwind class | 說明 |
|------|---------------|------|
| Header 背景 | `bg-teal-700` | 主視覺色 |
| Header 文字 | `text-white` | |
| 距離數字 | `text-teal-700` | 卡片內強調 |
| 按鈕背景 | `bg-teal-700` | 操作按鈕 |
| 路線 tag | `bg-teal-50 text-teal-700` | 淡色底 |

### 輔色：黃色（垃圾車主題）

| 用途 | Tailwind class | 說明 |
|------|---------------|------|
| 頁面 icon / emoji | 🟡 或 🚛 | 呼應台北垃圾車車身色 |
| 「現正停靠」tag | `bg-amber-100 text-amber-800` | 暖黃，提示感 |

### 非營業日：Gray（週三、週日）

| 用途 | Tailwind class | 說明 |
|------|---------------|------|
| Header 背景 | `bg-gray-400` | 明確降調，視覺感降溫 |
| Header 文字 | `text-white` | |
| 休息提示文字 | `text-gray-100` | 柔和，非錯誤感 |

### 其他 UI 元素

| 用途 | Tailwind class |
|------|---------------|
| 頁面背景 | `bg-gray-100` |
| 資訊卡背景 | `bg-white` |
| 卡片陰影 | `shadow-sm rounded-xl` |
| 時間 tag | `bg-gray-100 text-gray-600` |
| 「X 分鐘後抵達」tag | `bg-sky-100 text-sky-700` |
| 按鈕 disabled | `bg-gray-300 text-gray-500` |

## 版面結構

```
┌─────────────────────────────────┐
│  bg-teal-700（有車日）           │  ← Header
│  🚛 附近垃圾車                   │
│  今日 200 公尺內所有站點           │
└─────────────────────────────────┘
  ┌───────────────────────────────┐
  │  [現在之後還有幾班？]  button   │  ← Toolbar（定位後顯示）
  └───────────────────────────────┘
  找到 N 個站點                      ← Summary
  ┌───────────────────────────────┐
  │  123  │ 臺北市○○路○號          │  ← Card
  │  公尺  │ 🕐 18:00–18:10        │
  │        │ 中山-1  🟡 現正停靠   │
  └───────────────────────────────┘

──── 非營業日 ────

┌─────────────────────────────────┐
│  bg-gray-400（休息日）           │  ← Header 改色
│  🚛 附近垃圾車                   │
│  今日（週三）垃圾車休息，明天見。  │
└─────────────────────────────────┘
```

## 狀態別配色一覽

| 狀態 | Header 背景 | 說明文字色 |
|------|------------|-----------|
| 有車日（正常） | `bg-teal-700` | `text-white` |
| 休息日 | `bg-gray-400` | `text-white` |
| 定位失敗 / 錯誤 | `bg-teal-700`（保持） | 內文用 `text-red-500` |
