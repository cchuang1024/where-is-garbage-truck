# SPEC — feat-002：接下來的垃圾車

## 使用情境

使用者已知道今天附近有哪些站點（feat-001），但想快速知道**現在之後還有哪些班次**，不需要自己看時間判斷。按下按鈕，立刻只顯示「還沒走」的站點。

## 新增元素

在 feat-001 的全天清單下方（或上方固定區塊），新增一個按鈕：

> **「現在之後還有幾班？」**

## 行為

1. 按下按鈕時，取得當下時間
2. 在 200 公尺內的站點中，篩選 **離開時間 ≥ 現在** 的站點
3. 結果取代（或切換）原本的全天清單顯示
4. 每個站點額外顯示「距離發車還有幾分鐘」或「正在等車（已抵達）」的狀態標籤

## 時間判斷邏輯

| 條件 | 狀態標籤 |
|------|----------|
| 抵達時間 > 現在 | 「XX 分鐘後抵達」 |
| 抵達時間 ≤ 現在 ≤ 離開時間 | 「現正停靠」 |

只顯示離開時間 ≥ 現在的站點（已離開的不顯示）。

## 排序

依抵達時間由早到晚（最快到的排最前面）。

## 邊界條件

| 情況 | 處理方式 |
|------|----------|
| 今日剩餘班次為零 | 顯示「今日附近班次已全數離站」 |
| 尚未完成定位 | 按鈕不可用（灰色），定位完成後才啟用 |
| 今日為休息日 | 同 feat-001，不顯示按鈕 |

## 與 feat-001 的關係

- feat-001 的全天清單繼續存在
- 按鈕按下後切換到「接下來」檢視
- 提供方式回到全天清單（例如第二次按鈕或標題連結）

## 不在本 feature 範圍內

- 自動更新（每分鐘重新計算）
- 距離範圍調整
- 地圖顯示
