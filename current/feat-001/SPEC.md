# SPEC — feat-001：附近全天垃圾車站點

## 使用情境

使用者當天早上出門前、或隨時想查詢，打開網頁，不需要任何操作，頁面自動定位並列出**今天整天**會停在附近的所有垃圾車站點。

## 觸發方式

- 頁面載入後自動執行，**無需按鈕**
- 自動向使用者請求定位權限

## 定位與範圍

- 以使用者目前 GPS 位置為中心
- 顯示半徑 **200 公尺以內**的所有站點
- 距離計算以 Haversine 公式為準

## 顯示內容

每個符合條件的站點顯示：

| 欄位 | 說明 |
|------|------|
| 距離 | 距使用者的直線距離，單位公尺，四捨五入至整數 |
| 地點 | 原始地址描述（來自資料集） |
| 抵達時間 | 格式化為 `HH:MM` |
| 離開時間 | 格式化為 `HH:MM` |
| 路線 | 路線名稱（如「中山-1」） |

## 排序

依抵達時間由早到晚排序（同一地點一整天可能有多班次）。

## 邊界條件與例外處理

| 情況 | 處理方式 |
|------|----------|
| 使用者拒絕定位 | 顯示提示：「需要定位權限才能查詢附近站點」 |
| 定位逾時或失敗 | 顯示提示：「定位失敗，請確認裝置 GPS 已開啟」 |
| 200 公尺內無站點 | 顯示提示：「附近無垃圾車站點」 |
| 今日為週三或週日 | 顯示提示：「今日（週X）垃圾車休息」，不執行查詢 |

## 不在本 feature 範圍內

- 時間篩選（只顯示「現在附近」的車）
- 資源回收資訊
- 手動重新整理按鈕
- 地圖顯示
